One funny one-line review a dog gives the mailman, under 200 characters.
Entry for the [make.fun bounty](https://make.fun/bounty/u-motasimfuad-the-dog-reviews-the-mailman-87608f85).

## Run

```sh
python3 main.py
```

Writes the review to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## Entry

> Shows up daily, shoves paper through my slot, and runs off before I can file a complaint. Four stars, strictly for consistency.
